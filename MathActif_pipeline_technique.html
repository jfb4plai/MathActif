1. Import .docx Navigateur Extraction du texte + détection des équations Word natives JavaScript
(React front) 		mammoth.js — parse .docx
extractDocxMath.js — custom OMML→texte 		Les équations Word sont en OMML (XML natif). mammoth les ignore ; un parser custom les lit et les convertit en LaTeX intermédiaire $...$
2. Import PDF / image Serveur Vercel OCR + reconnaissance des expressions mathématiques Node.js
(serverless) 		Claude Sonnet Vision
/api/extract.js
Anthropic API 		Sonnet lit l'image et restitue le LaTeX exact de chaque équation. Un OCR classique (Tesseract) échoue sur ∫, Σ, fractions. Sonnet les lit nativement.
3. Protection des équations Navigateur Remplacement de chaque formule par un token opaque avant envoi à Haiku JavaScript mathProtect.js — custom
Regex + Map 		Sans cette étape, Haiku reformule les équations : f'(x) devient « la dérivée de f », ∫ disparaît. Les tokens «MATH_N» sont déplacés sans être touchés.
4. Génération AU (IA) Serveur Vercel Numérotation, zones de travail, même plan, Données/Inconnues Node.js
(serverless) 		Claude Haiku
claude-haiku-4-5-20251001
max_tokens : 3 000 		Haiku restructure le document sans toucher aux équations. Le budget token est critique : 3 000 tokens ≈ 18 exercices max. Au-delà, le document est tronqué silencieusement.
5. Injection pédagogique Navigateur Section Méthode (étapes) + formules RAPPEL sélectionnées ajoutées en tête JavaScript methodeTemplates.js
rappelData.js
(modules custom) 		Ces contenus sont statiques et garantis — ils ne passent pas par Haiku. L'enseignant les édite (80/20). Les formules RAPPEL sont en Unicode pur (∫, ², √) : lisibles sans plugin.
4b. Validation AU Navigateur 5 règles vérifiées côté client avant tout export ; deux règles bloquantes JavaScript validateMathAuRules() — custom
Regex sur le texte restauré 		Règles vérifiées : exercices numérotés, zones de travail présentes (___), même plan, équations restaurées, absence de [? ?]. Export bloqué si token «MATH_N» résiduel ou passage incertain non résolu — un exposant mal lu change tout l'exercice.
6. Export .docx Navigateur Génération du fichier Word téléchargeable avec équations natives JavaScript docx.js v9.6.1 — génération Word
file-saver — téléchargement
exportMathDocx.js — custom 		Les $\frac{A}{B}$ sont convertis en OMML natif (MathFraction, MathRadical, MathIntegral…). Éditables dans Word et MathType. keepNext garantit énoncé + zone de travail sur la même page.
Point clé pour un référent numérique : le format OMML est le seul format d'équation nativement éditable dans Word, sans plugin. Le choix de docx.js v9 (qui génère du vrai OMML) est la différence entre un document « image » et un document « vivant » — l'enseignant peut corriger une coquille directement dans Word ou MathType, sans repasser par l'application.
